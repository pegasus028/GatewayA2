## This stage in one sentence
Give good advice with should and shouldn't — and get the form right every time.

The stage has 2 modules, in this order: (1) should: the form; (2) Giving advice.

## Module 1: should: the form
Student's Book p.85, p.88 · level A2

**The key idea:** *should* + base verb — the same for everyone. No *to*, no *-s*, no *do*.

*Should* means “it's a good idea”. *Shouldn't* means “it's not a good idea”. *You should drink more water. You shouldn't eat a lot of sweets.*

The form never changes: *I / you / he / she / we / they should eat*. After *should*, use the base verb: ✗ *should to eat*, ✗ *should eats*, ✗ *She shoulds*.

Negative: *shouldn't* (= should not), never ✗ *don't should*. Questions: put *should* first — *Should I eat fish? What should we do?* (✗ *Do I should…?*) Short answers: *Yes, you should. / No, you shouldn't.*

When you speak, *should* is usually short and weak, but *shouldn't* is strong. Listen for the *n't*!

Pattern table:
- Form | Example
- + | should + verb | She should go to bed early.
- – | shouldn't + verb | You shouldn't stay up late.
- ? | Should + I/you… + verb? | Should I bring some food?
- Short answers | Yes, … should. / No, … shouldn't. | Yes, you should.

Good examples:
- Mek **should eat** more vegetables.
- **Should I bring** my own drink?

Classic mistakes and their corrections:
- Wrong: "We should to go home now." → Right: "We should go home now."
- Wrong: "Fah shoulds study harder." → Right: "Fah should study harder."
- Wrong: "Do we should call him?" → Right: "Should we call him?"
- Wrong: "You don't should drink so much cola." → Right: "You shouldn't drink so much cola."

Memory tip: Should works like can: no to, no -s, no do. You never say “He cans”, so don't say “He shoulds”!

## Module 2: Giving advice
Student's Book p.85, p.146 · level A2

**The key idea:** Problem → advice. Use *You should…* for a good idea, and *You shouldn't…* or *I don't think you should…* for a bad idea.

First listen to the problem. Then give a good idea: *“I'm always tired.” — “You should go to bed earlier.”* Or say what's a bad idea: *“You shouldn't play games so late.”*

Make your advice softer with *I think*: *I think you should see a doctor.* For a negative, English speakers usually say *I don't think you should…*: *I don't think you should eat that — it smells bad!*

Ask for advice with *What should I do?* or *Should I…?*: *Should I tell the teacher?*

*Should* is advice — you can choose. *Must* is a strong rule — no choice: *You must wear a helmet on a motorbike.* but *You should try the mango sticky rice.*

Pattern table:
- Problem | Good idea ✓ | Bad idea ✗
- I'm thirsty. | You should drink some water. | You shouldn't drink a lot of cola.
- I've got toothache. | You should see a dentist. | You shouldn't eat a lot of sweets.
- I'm always tired. | I think you should go to bed earlier. | I don't think you should play games all night.

Good examples:
- I've got a stomach ache. — You **shouldn't** eat any more cake!
- **I don't think you should** go out in this storm.
- Mek wants to get fit. He **should** play football more often.

Classic mistakes and their corrections:
- Wrong: "I'm hungry. — You should go to bed." → Right: "I'm hungry. — You should eat something."
- Wrong: "You should to see a doctor." → Right: "You should see a doctor."

Extra: *I think you shouldn't…* is not wrong, but *I don't think you should…* is more common and sounds friendlier.

Memory tip: Good advice fits the problem: tired → sleep, hungry → eat, toothache → dentist.

## Quick challenge for the end of the episode
Question: You look tired, Ploy. You should (blank) to bed early tonight.
Options: (A) going  (B) to go  (C) goes  (D) go
Answer: go — After *should*, use the base verb: *should go*. No *to*, no *-s*, no *-ing*.
