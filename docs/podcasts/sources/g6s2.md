## This stage in one sentence
Fill your shopping bag: a or an, some or any, there is or there are — and how to offer and ask politely.

The stage has 4 modules, in this order: (1) a or an?; (2) some or any?; (3) There is / There are; (4) Offers and requests.

## Module 1: a or an?
Student's Book p.80, p.88 · level A2

**The key idea:** Listen, don't look! Use *an* before a vowel **sound** (*an egg, an hour*) and *a* before a consonant sound (*a banana, a uniform*).

*A* and *an* mean “one”. Use them only with singular countable nouns: *an apple, a pear*. Never with plurals (✗ *a grapes*) or uncountable nouns (✗ *a rice*).

Most of the time the first letter helps: a, e, i, o, u → *an*: *an onion, an egg, an orange*. Other letters → *a*: *a sausage, a tomato*.

But English spelling plays tricks. The rule is about the first **sound**. In *hour* the h is silent, so it sounds like “our”: *an hour*. *Uniform* starts with a “you” sound: *a uniform*.

If an adjective comes first, the adjective decides: *an egg* but *a big egg*; *a sandwich* but *an egg sandwich*.

Pattern table:
- First sound | Use | Examples
- vowel sound (a, e, i, o, u) | an | an apple, an egg, an onion
- silent h → vowel sound | an | an hour
- “you” sound (u, eu) | a | a uniform, a university
- consonant sound | a | a melon, a big apple

Good examples:
- I eat **an** orange every morning.
- We waited for **an** hour at the bus stop.
- Pim wears **a** uniform at school.

Classic mistakes and their corrections:
- Wrong: "Can I have a apple, please?" → Right: "Can I have an apple, please?"
- Wrong: "He had an big egg for breakfast." → Right: "He had a big egg for breakfast."
- Wrong: "I want a grapes." → Right: "I want some grapes. / I want a grape."

Extra: Letters said by their name follow the sound too: *an MP3 player* (M sounds like “em”) — that's the book's own example on p.88.

Memory tip: Say it aloud: “a apple” is hard to say, “an apple” flows. Your mouth knows the rule!

## Module 2: some or any?
Student's Book p.80, p.88 · level A2

**The key idea:** *some* in positive sentences; *any* in negatives and questions — with plural nouns (*eggs*) and uncountable nouns (*milk*).

*Some* and *any* mean “a number of” or “an amount of” when the exact number isn't important. Use them with plural countable nouns and uncountable nouns — not with one thing (✗ *some apple* → *an apple*).

Positive sentence → *some*: *We've got some eggs. There's some milk.* Negative sentence (with *not / n't*) → *any*: *We haven't got any eggs. There isn't any milk.*

Question → *any*: *Have you got any eggs? Is there any milk?* (Offers and requests are different — see the Extra module *Offers and requests*.)

Pattern table:
- Plural countable | Uncountable
- + | I've got **some** grapes. | I've got **some** rice.
- – | I haven't got **any** grapes. | I haven't got **any** rice.
- ? | Have you got **any** grapes? | Have you got **any** rice?

Good examples:
- There are **some** mushrooms in the soup.
- We don't have **any** sugar.
- Are there **any** onions in this salad?

Classic mistakes and their corrections:
- Wrong: "He hasn't got some homework." → Right: "He hasn't got any homework."
- Wrong: "I've got any friends in Phuket." → Right: "I've got some friends in Phuket."
- Wrong: "I need some flower for Mum." → Right: "I need some flowers / a flower for Mum."

Extra: Not every question takes *any*. When you **offer** or **ask for** something, use *some*: *Would you like some tea? Can I have some water?*

Memory tip: Some = sure (+). Any = not or ? (–, ?).

## Module 3: There is / There are
Student's Book p.81, p.89 · level A2

**The key idea:** To say something is in a place, use *There is* (+ one thing or uncountable) or *There are* (+ plural) — not *have*.

*There's* + *a/an* + singular noun: *There's an apple in my bag.* *There's* + *some* + uncountable: *There's some rice.* *There are* + *some* + plural: *There are some grapes.*

Negatives: *There isn't any milk. There aren't any eggs.* Questions: put *is/are* first — *Is there any milk? Are there any eggs?* Short answers: *Yes, there is. / No, there aren't.*

Careful: in some languages one word means both “have” and “there is”. In English they are different. *Have* needs an owner: *I have a dog. My school has a pool.* For what exists in a place, use *there is/are*: *There are a lot of cars in Bangkok.* (✗ *In Bangkok have a lot of cars.*)

Pattern table:
- + | – | ?
- one thing | There's an egg. | There isn't an egg. | Is there an egg?
- uncountable | There's some milk. | There isn't any milk. | Is there any milk?
- plural | There are some eggs. | There aren't any eggs. | Are there any eggs?

Good examples:
- **There are** a lot of food stalls at the night market.
- **Is there** any water in the bottle? — No, there isn't.

Classic mistakes and their corrections:
- Wrong: "In my school have a big canteen." → Right: "There's a big canteen at my school. / My school has a big canteen."
- Wrong: "There is some grapes in the bowl." → Right: "There are some grapes in the bowl."
- Wrong: "There has a 7-Eleven near my house." → Right: "There's a 7-Eleven near my house."

Memory tip: Something in a place? Start with There is / There are. Something you own? Use have.

## Module 4: Offers and requests
Student's Book p.86, p.146 · level A2 · an EXTRA module (beyond the book, useful for the entrance exam)

**The key idea:** Questions usually take *any* — but when you **offer** something or **ask for** something, use *some*: *Would you like some tea? Can I have some water?*

The book rule says: questions → *any*. That's true for questions that ask for information: *Is there any milk?* (I don't know — tell me.)

But some questions are really offers or requests. You expect the answer “yes”, so English uses *some*. Offer = you give: *Would you like some cake?* Request = you ask for: *Can I have some water, please? Could we have some bread?*

With one countable thing, use *a/an* as usual: *Would you like an apple? Could I have a burger, please?*

Pattern table:
- Kind of question | Example | Word
- asking for information | Are there any onions in it? | any
- offer (you give) | Would you like some juice? | some
- request (you ask for) | Can I have some bread, please? | some

Good examples:
- **Would you like some** rice with your curry?
- Could I have **some** water, please?
- Is there **any** sugar in this? I don't eat sugar.

Classic mistakes and their corrections:
- Wrong: "Would you like any tea?" → Right: "Would you like some tea?"

Extra: The book's rule box only says “any in questions”. Asking if a shop or café has something is a normal question: *Have you got any orange juice?* (Speaking bank, p.86). Asking for it is a request: *Can I have some orange juice?*

Memory tip: Giving or asking for something? Say some. Just asking for information? Say any.

Options: (A) an oranges  (B) a oranges  (C) an orange  (D) a orange
Answer: an orange — *Orange* starts with a vowel sound, so use *an*: *an orange*. *A* and *an* mean one thing, so no *-s*.
