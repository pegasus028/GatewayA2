## The pattern
**A storm, two storms — but some rain, never two rains**

Remember Unit 6: some nouns you can count and some you can't. Weather works the same way. A storm and a cloud have edges: one storm ends and another starts, so you can count them (two storms, a lot of clouds). Rain, snow, fog and ice are 'stuff', like water or rice: you measure them, you don't count them (a lot of rain, not much snow, some ice). So ask How many storms…? but How much rain…? When you need to count stuff, use a unit, just like a bottle of water: a drop of rain, an ice cube. Wind can be both: a strong wind, strong winds, a lot of wind. And there is only one sun: the sun.

Examples:
- How many **storms** were there this year?
- How much **rain** was there in October?
- There were a lot of **clouds**, but there wasn't much **snow**.

Unit words that follow this pattern: storm, cloud, rain, snow, fog, ice, wind, sun, sky.
